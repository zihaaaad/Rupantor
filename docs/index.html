Features

Built for people who ship work, not licences.

Everything below is in the free download. There is no upgrade to buy.

One-click OS font install

Drop in .ttf or .otf files, preview the whole waterfall, then install or uninstall them for real — through the Windows registry with a WM_FONTCHANGE broadcast, or ~/Library/Fonts on macOS. Your other apps pick them up immediately.

Native Adobe execution

Run .jsx scripts in Photoshop, Illustrator, and After Effects through a COM bridge on Windows and AppleScript on macOS.

Local asset vault

Imported fonts and scripts are copied into a persistent vault, so deleting the original download never breaks your library.

Full Unicode support

Bangla, Arabic, Cyrillic, CJK — complex scripts import and render cleanly, without mangling font names on the way into the registry.

Built-in script editor

Tweak a variable and save in place. No round trip through a separate editor just to change one value.

Auto-updates, no strings

New releases are checked on launch and every few hours, then installed once you confirm. Updates ship straight from GitHub Releases — the same artifacts you can build yourself from source.

Getting started

Three steps. No sign-up anywhere.

  1. 01

    Download and install

    Grab the Windows installer or the macOS .dmg above. Builds are unsigned, so approve the first-run OS prompt.

  2. 02

    Open it

    That is the whole setup. The app opens straight into your library — nothing to activate, nothing to enter.

  3. 03

    Drop in your assets

    Drag fonts and .jsx scripts onto the window. Install fonts, run scripts, get back to work.

FAQ

Straight answers.

Is it really free? What is the catch?

There is no catch. Rupantor is released under the MIT licence: use it personally or commercially, modify it, redistribute it. No feature is held back and nothing expires.

Do I need an account or a licence key?

No. There is no account system, no key, and no activation server. Install it and it runs.

Does it send my data anywhere?

No. Your fonts, scripts, and settings live in a local file on your own machine. The only network request the app makes is checking GitHub for a newer release.

Why does Windows or macOS warn me on first run?

The installers are not code-signed — a signing certificate is an ongoing cost this project does not carry. The source is public, so you can always build it yourself instead.

Which platforms are supported?

Windows and macOS (Apple Silicon). There is no Linux build, since the Adobe automation Rupantor is built around does not exist there.
